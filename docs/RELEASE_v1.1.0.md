# VPN Shop Bot v1.1.0

Релиз вокруг **операторского опыта**: установка одной командой, админка (финансы, продление, диагностика) и честная автодиагностика панелей.

Предыдущий релиз: [v1.0.1](https://github.com/Sp0nge-bob/xuibot/releases/tag/v1.0.1) (полировка deploy CLI).

**Стек:** Platega + 3x-ui · Python 3.11–3.14 · aiogram 3 · FastAPI · SQLite · Redis FSM

---

## Установка с нуля (одна команда)

```bash
curl -fsSL https://raw.githubusercontent.com/Sp0nge-bob/xuibot/main/deploy/install.sh \
  | sudo bash
```

Мастер (`deploy/install.sh`):

- скачивает **последний GitHub Release**;
- спрашивает `BOT_TOKEN` и **сразу проверяет** его через Telegram `getMe`;
- настраивает Primary 3x-ui; Platega — опционально (иначе `TEST_MODE=true`);
- ставит Redis, venv, systemd и запускает службы.

Каталог по умолчанию: `/opt/vpn-bot`.

## Обновление с 1.0.x

```bash
cd /opt/vpn-bot   # или ваш APP_DIR
sudo bash deploy/vpn-bot-ctl.sh update
# меню → пункт 2 (stable)
```

Если ctl ещё очень старый:

```bash
curl -fsSL https://raw.githubusercontent.com/Sp0nge-bob/xuibot/main/deploy/install.sh \
  | sudo bash -s -- /opt/vpn-bot
```
