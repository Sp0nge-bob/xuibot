# CaelixFlow Telegram Bot — security candidate 2026-11-01

**Для push/review. Не production-ready; не опубликован и не развёрнут.**
Ветка: `security-fixes/2026-11-01`. Исходный commit: `4960c9f5cc2b0546d11106bc21447af43bbf68e3`.

## Изменения

- Проверка ключа шифрования до записи в БД и обращения к панелям. Удалены неявные публичные fallback-ключи; текущие HKDF/SHA и явный OLD_SECRET_KEY сохранены.
- Удалены секрет ссылки и Redis credentials из выбранных диагностических сообщений.
- Привязка Telegram/email выполняется одной транзакцией с проверкой конфликтов и блокировок. Добавлена совместимая email_blacklist для самостоятельной работы бота.
- Новые заказы явно записывают source=bot. Переполненная очередь освобождает reservation и отвечает503.
- Тесты backup используют изолированные данные и проверяют целостность восстановленного SQLite.

## Совместимость

Публичные HTTP paths/methods/signatures сохранены. Рабочие данные, действующие
VPN credentials, настройки реальных серверов и зависимости не менялись.
Небезопасные конфигурации/запросы намеренно отклоняются. Общая криптография и
конкурентная привязка бота/сайта проверены на фиктивной общей SQLite.
