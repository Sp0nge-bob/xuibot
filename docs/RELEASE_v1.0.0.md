# VPN Shop Bot v1.0.0

Первый стабильный релиз Telegram-бота для продажи VPN-подписок.

**Стек:** Platega (оплата) + 3x-ui (выдача ключей) · Python **3.11–3.14** · aiogram 3 · FastAPI · SQLite · Redis FSM.

---

## Зачем этот бот

- Готовый магазин VPN «под ключ»: тарифы, оплата, выдача ссылки/QR, поддержка, админка.
- Клиенту не показывают внутренности панели — только понятный продукт.
- Оператору — systemd CLI: установка, **stable**-релиз или **edge**-коммит одной командой.

---

## Возможности

### Для клиентов
- Тарифы с ценами из админки
- Оплата через **Platega** (СБП, карта, крипто и др.)
- Пробный период, промокоды (скидка / бесплатный тариф)
- Реферальная программа
- Подписка: QR + ссылка (в т.ч. Happ crypt3/crypt5)
- FAQ, тикеты поддержки, возвраты
- Предупреждение, если вторичный сервер недоступен

### Для оператора
- Hub `/admin`: клиенты, ноды 3x-ui, инбаунды, лимит IP, Happ, FAQ, логи, бэкап
- Multi-node: ★ Primary + вторичные (синк панелью)
- Диагностика, lockdown, TEST_MODE
- Автобэкап БД, напоминания об окончании подписки
- Обновление **без локального git**: архив Release или последнего коммита

## Обновление / установка (CLI)

```bash
# С нуля или починить ctl:
curl -fsSL https://raw.githubusercontent.com/Sp0nge-bob/xuibot/main/deploy/bootstrap.sh \
  | sudo bash -s -- /opt/vpn-bot

cd /opt/vpn-bot
# заполните .env при первом запуске
sudo bash deploy/vpn-bot-ctl.sh          # меню
# 1 — окружение (+ Redis)
# 2 — обновить до последнего релиза (stable)  ← рекомендуется
# 3 — обновить до последнего коммита (edge)

# Неинтерактивно:
sudo bash deploy/vpn-bot-ctl.sh update           # stable
sudo bash deploy/vpn-bot-ctl.sh update --edge    # main
```

Сохраняются: `.env`, `data/`, `.venv/`.
