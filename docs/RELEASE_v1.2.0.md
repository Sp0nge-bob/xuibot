# VPN Shop Bot v1.2.0 — Web Ecosystem & Node Scaling

Релиз **v1.2.0** представляет полноценную интеграцию с независимым веб-порталом [VPN Web Portal](https://github.com/Sp0nge-bob/vpnwebsite.git), масштабную оптимизацию производительности базы данных, нативную поддержку пакетных операций 3x-ui (`bulkAdjust`) и усиленную систему безопасности.

Предыдущий релиз: [v1.1.0](https://github.com/Sp0nge-bob/xuibot/releases/tag/v1.1.0).

**Стек:** Platega + 3x-ui · Python 3.11–3.14 · aiogram 3 · FastAPI · SQLite (WAL) · Redis FSM

---

## Ключевые нововведения

### 1. Единая кроссплатформенная экосистема с Веб-порталом
- **Общая база данных:** Синхронизация в реальном времени через SQLite WAL между Telegram-ботом и FastAPI веб-сервисом (`vpnwebsite`).
- **Связывание аккаунтов через Email и Deep-link:** Пользователи могут связывать свои профили в Telegram и на сайте через OTP-код или переходом по одноразовой ссылке `/start link_<token>`.
- **Разделение подписок при отвязке/блокировке:** Чёткая изоляция источников (`bot` vs `web`). При отвязке почты или внесении email в чёрный список бот-подписки остаются у Telegram-пользователя, а веб-подписки изолируются.
- **Анонимизация клиентов 3x-ui:** Автоматическая генерация и распознавание почтовых и анонимных идентификаторов клиентов `web{user_id}` и `web{user_id}_{sub_id}` без конфликтов с ботом.
- **Сохранение клиентских групп:** Фиксация группы `telegram-bot` в 3x-ui для клиентов бота при продлениях и синхронизации.
- **Smart Webhook Proxying:** Вебхуки от платёжного шлюза Platega, приходящие в бот с заказами веб-сайта, прозрачно и надёжно проксируются в сервис сайта (порт 8090/8080) с фолбэком на прямое обновление БД.
- **Многоисточниковый поиск sub_id:** Поддержка поиска клиентов по `sub_id`, `subId` и `email` в единой утилите сверки `reconcile_sub_ids.py`.

### 2. Масштабирование и оптимизация узлов 3x-ui
- **Нативный bulkAdjust:** Переход на официальный эндпоинт 3x-ui `bulkAdjust` для пакетного продления и корректировки времени клиентов на узлах с увеличенным таймаутом (до 5 минут) для предотвращения разрыва HTTP-сессий.
- **Ротация ссылок подписки (Rotate subId):** Возможность административной или пользовательской перегенерации `subId` без потери данных клиента и без изменения UUID.
- **Шифрование секретов узлов (Fernet):** Поддержка зашифрованных токенов доступа к нодам в таблице `xui_nodes` (`enc:v1:...`) с прозрачной дешифрацией.
- **Политика IP Limit:** Ограничение `limit_ip` теперь применяется только к вновь создаваемым клиентам, не затрагивая конфигурации существующих активных пользователей.

### 3. Производительность и надёжность базы данных
- **SQLite PRAGMA Performance:** Включение параметров высокой производительности и конкурентности:
  - `PRAGMA journal_mode = WAL`
  - `PRAGMA synchronous = NORMAL`
  - `PRAGMA busy_timeout = 60000` (предотвращение ошибок `database is locked`)
  - `PRAGMA cache_size = -64000`
- **Очистка устаревших подписок:** Автоматический сервис `expired_purge.py` для безопасного удаления неактивных подписок по истечении заданного срока (`EXPIRED_PURGE_AFTER_DAYS`) с очисткой тикетов и возвратов.
- **Резервное копирование:** Автоматизированное создание бэкапов SQLite баз данных всех подключенных 3x-ui нод в архивные каталоги.

### 4. Безопасность и Чёрный список (Blacklist)
- **Запрет привязки заблокированных Email:** Невозможность привязать email из чёрного списка к Telegram-аккаунту.
- **Автоматическая отвязка при бане:** При внесении пользователя или почты в бан на сайте происходит мгновенная отвязка от Telegram и деактивация доступа в панелях.

## Сводка изменений (Changelog)

| Область | Описание |
|---------|----------|
| **Web Sync** | Поддержка deep-link `/start token`, связывание через OTP, proxying Platega webhook |
| **Separation** | Разделение подписок web и bot при отвязке почты и обработке блокировок |
| **3x-ui** | Внедрение нативного `bulkAdjust` с таймаутом 5 минут; ротация `subId` |
| **Nodes** | Шифрование токенов доступа к нодам (Fernet `enc:v1:...`), бэкапы БД нод |
| **Database** | Настройка PRAGMA (WAL, busy_timeout 60s, synchronous NORMAL), фоновая очистка |
| **Admin** | Массовая рассылка, пакетное добавление дней (`addDays`), ротация ссылок |
| **Security** | Проверка чёрного списка при привязке почты, авто-отвязка при бане |

## Обновление на сервере

Для перехода на версию **v1.2.0**:

```bash
sudo vpnplategabot update
```

Либо вручную:
```bash
cd /opt/vpn-bot
git pull origin main
source .venv/bin/activate
pip install -e .
sudo systemctl restart vpn-bot
```
